# GTA VI Companion — Rabbit R1 Creation

Unofficial fan companion for GTA VI on the Rabbit R1 (240x282).

- **Hidden Loot** — 38 Illegal Operations & hidden discoveries with loot rarity glow (gold = legendary, purple = epic, green = cash/sellables), guard levels, safe codes, step-by-step directions and a Find It tab with map screenshots.
- **Easter Eggs** — 23 multi-source verified secrets with photos, directions and map views.
- **Story Progression** — all 91 main missions in order across 5 chapters, each with overview, tips, verified rewards (unverified rewards are labelled, never invented) and missable warnings.

Data lives in `data.json`, loaded fresh on every open, so content updates land without reinstalling the creation. Progress (missions done / loot found / eggs seen) is stored on-device in localStorage.
